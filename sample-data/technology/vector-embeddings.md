# Vector Embeddings for Meaning Search

A text embedding model converts language into a dense vector of numbers. Nearby vectors often represent related meanings, even when the original words do not overlap. Retrieval systems can compare a query vector with document vectors using cosine similarity.

Hybrid search complements embeddings with keyword ranking. Exact names and product codes are often better found lexically, while paraphrases benefit from semantic distance. Model quality, normalization, document granularity, and diversity of the corpus all influence the result. Embeddings also compress meaning, so collisions and cultural differences can distort similarity.
